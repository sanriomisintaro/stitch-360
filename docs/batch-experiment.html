Metric definition

SSIM is computed on Rec. 709 luminance using a 7×7 uniform local window, valid-window centers only, and sample covariance. Seam metrics are calculated within bands around the nominal ±90° crossover meridians. Controlled perturbations can be introduced at synthetic-capture time using a right-lens photometric gain and/or a generator-only FOV offset. With both set to their neutral values (gain 1.00, FOV delta 0°), the experiment is a clean matched-model round trip; non-neutral values create known mismatch conditions for sensitivity experiments.
