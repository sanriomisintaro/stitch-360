# Stitch 360 v1.0.0 — Research Release

This is the frozen software/reproducibility artifact associated with the Stitch 360 study. The release contains the application and research code, six procedural synthetic stimuli, real-camera metadata, the frozen calibration, automated tests, and machine-readable versions of the manuscript summary tables.

The journal manuscript, cover letter, suggested reviewers, and other editorial files are intentionally excluded. Original real-camera JPEGs are also excluded because some scenes contain identifiable people and redistribution must respect privacy/consent constraints.

The manuscript reports FFmpeg `v360` as the reproducible external direct-projection baseline. Optional Hugin utilities remain in the repository for future experiments but should not be interpreted as part of the reported v1.0.0 results.
